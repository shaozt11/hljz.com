SDK v2 / REFERENCE

RoxetOS SDK v2
完整参考文档

本页整合了 API Reference 和开发者适配指南，覆盖宿主桥接、应用私有存储、原生弹窗、协同会话、错误码和发布验收。

1. OVERVIEW

概述

RoxetOS 采用“宿主 + 应用”模式，系统能力统一通过 `window.Roxet` 调用。

系统负责

桌面环境、窗口管理、文件管理、协同服务、原生弹窗和权限管理。

应用负责

业务逻辑、页面渲染、数据处理，并把结果写入自己的 `result/` 目录。

2. STRUCTURE

应用模型与目录结构

推荐把应用内容放在独立目录中，宿主会自动扫描 `result/`。

sys/
└── notes/
    ├── manifest.json
    ├── app.py
    ├── templates/
    ├── static/
    └── result/

`result/` 是应用私有输出目录，系统会自动扫描 `user/<username>/sys/*/result/**`。

3. MANIFEST

manifest.json 配置

最小配置和推荐配置都应明确应用标识、启动地址和运行环境。

最小配置 
{
  "id": "notes",
  "name": "Notes",
  "version": "1.0.0",
  "icon": "/static/icon.png",
  "launch": "http://127.0.0.1:5000"
}
推荐配置 
{
  "name": "氧分绘画",
  "icon": "/img/logo.png",
  "runtime": "flask",
  "port": 6303,
  "start_path": "",
  "platforms": ["win32", "linux", "darwin"]
}
4. BOOTSTRAP

初始化 SDK

先引入桥接脚本，再获取 `Shell Bridge` 实例。

桥接入口 
<script src="/sdk/roxet-bridge.js"></script>
<script>
  const shell = window.Roxet?.registerShellBridge?.()
</script>
能力入口 
const shell = window.Roxet?.registerShellBridge?.()
window.Roxet.storage
window.Roxet.ui
window.Roxet.sync
window.Roxet.version
5. SHELL BRIDGE

窗口与系统能力

保留 v1 的核心能力，用于通知、开窗和窗口控制。

notify()

`shell.notify(message, type)` 用于桌面通知。

openApp()

`shell.openApp(appId)` 用于打开系统应用。

窗口控制

`shell.focusWindow()`、`shell.minimizeWindow()`、`shell.closeWindow()` 负责窗口交互。

6. STORAGE API

存储能力

访问入口为 `window.Roxet.storage`，每个应用拥有独立目录。

常用接口 
window.Roxet.storage.list()
window.Roxet.storage.read(path)
window.Roxet.storage.write(path, data)
window.Roxet.storage.remove(path)
window.Roxet.storage.pickFolder()
约束
  • 默认只允许写入本应用的 `result/`。
  • 云文件会展示系统扫描到的结果文件。
  • 应用不能直接访问其他应用目录。
7. UI + 8. SYNC

原生弹窗与协同能力

复杂应用优先用宿主能力，避免自己在 iframe 里重造 UI 和同步层。

原生弹窗 
window.Roxet.ui.alert({ title, message })
window.Roxet.ui.confirm({ title, message })
window.Roxet.ui.prompt({ title, message, defaultValue })
window.Roxet.ui.custom({ title, content, actions })
协同会话 
const session = window.Roxet.sync.join({
  appId: "draw",
  mode: "collab"
})

适合画板、文档编辑器和需要实时同步状态的应用。

9. VERSION

版本与错误码

`window.Roxet.version` 返回 SDK 版本；失败时返回标准错误码。

版本信息 
console.log(window.Roxet.version)
// 输出: 2.0.0
常见错误码

`APP_NOT_FOUND`、`WINDOW_NOT_FOUND`、`ACCESS_DENIED`、`FILE_NOT_FOUND`、`INVALID_PATH`、`SESSION_NOT_FOUND`、`SESSION_CLOSED`、`INVALID_ARGUMENT`、`INTERNAL_ERROR`。

12. CHECKLIST

发布验收标准

发布前应满足下面的检查项。

  • `manifest.json` 配置正确。
  • 应用可正常启动，窗口关闭无异常。
  • 文件读写、原生弹窗和协同功能正常。
  • 不会访问未授权目录，控制台无错误输出。
