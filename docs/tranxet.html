产品概述

OVERVIEW // 兼容层定位

Tranxet 是面向 RoxetOS 的兼容层， 目标是让既有软件与其依赖在目标环境中保持运行， 从而降低向 RoxetOS 迁移的成本。

原 LayStore 应用商店平台已并入 Tranxet， 应用目录与分发能力随兼容层一并提供。

核心目标

  • 保持既有应用行为的一致性。
  • 减少迁移时的改造工作量。
  • 提供可验证的兼容性基线。
